# Security Policy

## Supported Versions

Only the latest tagged release receives security fixes.

| Version | Supported |
| ------- | --------- |
| 1.1.x   | ✅        |
| < 1.1   | ❌        |

## Reporting a Vulnerability

If you discover a security vulnerability in this package, please report it privately rather than
opening a public GitHub issue:

- Post in the [Security Room on Discord](https://discord.com/channels/1352854772859932702/1352854916690874388), or
- Use [GitHub's private vulnerability reporting](https://github.com/amjadiqbal/filament-url-image-uploader/security/advisories/new) for this repository.

Please include a description of the issue, steps to reproduce, and the affected version. All
reports will be acknowledged and addressed as quickly as possible; a fix will be released and
credited to the reporter unless anonymity is requested.

Do not disclose the vulnerability publicly until a fix has been released.
